# Changelog

## 0.2.1

- A picture that appears more than once (the same address, or the same image under a new address,
  as when a post is shared to several subreddits) is saved once. Every mention points to that file,
  and repeats don't count toward the picture limit.
- Profile snapshots say plainly when they hold everything Reddit lists for the account.
- Small icons are judged by a picture's real or declared size, so a picture that hasn't finished
  loading is no longer mistaken for one.

## 0.2.0

- Reddit profiles: click RedAnt on `reddit.com/user/NAME` to save the account's posts and comments,
  newest first, with pictures.
- The top of every `snapshot.md` gives its exact size (lines, words, characters).
- Share codes and ad trackers are removed from saved links.

## 0.1.0

- First version: Reddit threads (all comments and pictures), any web page (main text and pictures)
  and PDFs, saved to a folder in Downloads with the file path copied.
